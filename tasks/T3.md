# T3: testes para a T1

## Prompt (copie exatamente, com e sem portões)

> Write the Apex tests for the Case summary service from task T1. Put them in force-app/main/default/classes.

## Objetivo
Obter testes para o serviço da T1.

## Critério de aceite
- Cada teste tem asserts que provam comportamento, não só cobertura.
- Um teste roda como persona restrita (`System.runAs`) e espera a `QueryException` que cita `Internal_Notes__c`.
- Um teste roda como persona com permissão e espera o conteúdo `SECRET`.
- A criação de usuário não causa `MIXED_DML_OPERATION`.

## Armadilha esperada
O agente entrega um teste que insere um Case, chama o serviço como administrador e afirma só `r.size() > 0`. Cobertura alta, nenhuma prova sobre quem pode ver o quê.
